# UX Visual Foundation

Framework for establishing visual design groundwork including colors, typography, and spacing.

## Brand Guidelines Assessment

Before defining visual foundation, assess existing constraints:

- **Existing Brand Guidelines**: Color palettes, fonts, logo usage rules
- **Brand Personality**: Professional, friendly, modern, classic
- **Industry Standards**: Competitive visual expectations
- **Accessibility Requirements**: Contrast ratios, font size minimums

If no existing brand guidelines exist, generate theme options based on project personality and emotional goals.

## Color System

### Color Strategy Development

Define a comprehensive color system including:

- **Primary Colors**: Brand identity colors
- **Secondary Colors**: Supporting palette
- **Semantic Colors**: Success, warning, error, info
- **Neutral Colors**: Backgrounds, borders, text

### Accessibility Compliance

- Maintain WCAG 2.1 AA minimum contrast ratios (4.5:1 for normal text, 3:1 for large text)
- Test color combinations for color blindness compatibility
- Provide non-color indicators for critical information

### Color Application

- Define when and how each color is used
- Create color tokens for consistent application
- Document light/dark mode variations if applicable

## Typography System

### Typography Questions to Address

- What should the overall tone feel like? (Professional, friendly, modern, classic?)
- How much text content will users read? (Headings only? Long-form content?)
- What accessibility requirements exist for font sizes?
- Are there brand fonts that must be used?

### Type Scale Definition

Establish a consistent type scale:

| Element | Size | Weight | Line Height |
|---------|------|--------|-------------|
| H1 | - | - | - |
| H2 | - | - | - |
| H3 | - | - | - |
| Body | - | - | - |
| Caption | - | - | - |

### Typography Principles

- Choose primary and secondary typefaces with clear rationale
- Establish hierarchy through size, weight, and spacing
- Ensure readability across all device sizes
- Consider loading performance for web fonts

## Spacing and Grid System

### Spacing Strategy

- **Density**: Dense and efficient vs. airy and spacious
- **Base Unit**: Common choices are 4px, 8px, or 12px
- **White Space**: Relationship between elements
- **Consistent Rhythm**: Predictable spacing patterns

### Grid System

- Column structure (8, 12, 16 columns)
- Gutter widths
- Margin rules
- Breakpoint definitions

### Layout Principles

- Content density appropriate for use case
- Clear visual hierarchy through spacing
- Responsive behavior across breakpoints
- Component alignment and grouping rules

## Visual Hierarchy

### Establishing Priority

Use visual weight to guide user attention:

- **Size**: Larger elements draw more attention
- **Color**: High contrast for important elements
- **Position**: Top and left positions typically read first
- **Spacing**: Isolation increases importance
- **Typography**: Bolder weights signal importance

### Information Architecture

- Group related information visually
- Use progressive disclosure for complex information
- Create clear visual pathways through content
- Balance visual weight across layouts

## Accessibility Considerations

Visual foundation must support accessibility:

- **Color Contrast**: Meet WCAG requirements
- **Text Sizing**: Support browser zoom and text scaling
- **Focus Indicators**: Visible focus states for keyboard navigation
- **Motion**: Respect reduced motion preferences
- **Touch Targets**: Minimum 44px for mobile interfaces
