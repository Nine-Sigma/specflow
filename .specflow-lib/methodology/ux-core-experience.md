# UX Core Experience

Framework for defining the essential user experience and interaction principles.

## Core Action Identification

Start by identifying the most important user interaction:

**Key Questions:**
- What's the ONE thing users will do most frequently?
- What user action is absolutely critical to get right?
- What should be completely effortless for users?
- If we nail one interaction, everything else follows - what is it?

**Focus Area:** The core loop or primary action that defines your product's value.

## Platform Requirements

Determine where and how users will interact:

**Platform Questions:**
- Web, mobile app, desktop, or multiple platforms?
- Will this be primarily touch-based or mouse/keyboard?
- Any specific platform requirements or constraints?
- Do we need to consider offline functionality?
- Any device-specific capabilities we should leverage?

**Output:** Clear platform strategy with rationale.

## Effortless Interactions

Surface what should feel magical or completely seamless:

**Discovery Questions:**
- What user actions should feel completely natural and require zero thought?
- Where do users currently struggle with similar products?
- What interaction, if made effortless, would create delight?
- What should happen automatically without user intervention?
- Where can we eliminate steps that competitors require?

**Goal:** Identify friction points to eliminate and opportunities for seamless experiences.

## Critical Success Moments

Identify the moments that determine success or failure:

**Mapping Questions:**
- What's the moment where users realize "this is better"?
- When does the user feel successful or accomplished?
- What interaction, if failed, would ruin the experience?
- What are the make-or-break user flows?
- Where does first-time user success happen?

**Output:** Map of critical moments requiring exceptional UX attention.

## Experience Principles

Extract guiding principles from discovery conversations:

**Principle Categories:**
- Core action focus (what the product does best)
- Effortless interaction (what should be frictionless)
- Platform considerations (where and how users interact)
- Critical success moments (what determines user satisfaction)

**Format:**
- Principle 1: [Based on core action focus]
- Principle 2: [Based on effortless interactions]
- Principle 3: [Based on platform considerations]
- Principle 4: [Based on critical success moments]

These principles guide all subsequent UX decisions.

## Output Structure

When documenting core experience, include:

### Defining Experience

Core experience definition describing the primary user interaction and value delivery.

### Platform Strategy

Platform requirements and decisions with rationale for each choice.

### Effortless Interactions

Identified areas where interactions must be seamless, including:
- Friction points to eliminate
- Automation opportunities
- Competitive advantages

### Critical Success Moments

Make-or-break interactions mapped across the user journey:
- First-time user success points
- Repeated use satisfaction moments
- Recovery from error moments

### Experience Principles

Guiding principles for UX decisions, actionable and specific to this product.

## Application Guidelines

- Experience principles should be specific enough to resolve design debates
- Critical moments deserve disproportionate design attention
- Platform strategy should inform component and interaction choices
- Effortless interactions often require more engineering investment
- Validate principles against real user scenarios before finalizing
