# UX Discovery

Collaborative discovery methodology for understanding project context, users, and UX challenges.

## Discovery Sequence

### Phase 1: Context Review

Start by analyzing what we know from loaded documents:

- Summarize key insights from PRD, briefs, and other context documents
- Identify target users from documentation
- Extract key features and goals
- Confirm understanding with stakeholders
- Note any corrections or additions needed

### Phase 2: Gap Filling

If no documents were loaded or key information is missing, gather essentials:

- **What are you building?** (Describe the product in 1-2 sentences)
- **Who is this for?** (Describe ideal user or target audience)
- **What makes this special?** (Unique value proposition)
- **What's the main user action?** (Core user action or goal)

### Phase 3: User Context Exploration

Dive into user understanding with these questions:

**Problem Space:**
- What problem are users trying to solve?
- What frustrates them with current solutions?
- What would make them say "this is exactly what I needed"?

**User Characteristics:**
- How tech-savvy are target users?
- What devices will they use most?
- When and where will they use this product?

### Phase 4: Challenge Identification

Surface the key UX challenges to address:

**Design Challenges:**
- Identify 2-3 key UX challenges based on project type and user needs
- Note platform-specific considerations
- Highlight complex user flows or interactions

**Design Opportunities:**
- Identify 2-3 areas where great UX could create competitive advantage
- Note opportunities for innovative UX patterns

## Analysis Framework

When documenting discoveries, structure the output as:

### Executive Summary

Brief overview of the project from a UX perspective.

### Project Vision

Project vision summary synthesized from discovery conversations.

### Target Users

Detailed target user descriptions including:
- Demographics and characteristics
- Technical proficiency
- Usage context (devices, environment, frequency)
- Pain points and needs

### Key Design Challenges

UX challenges that must be addressed, including:
- Complexity barriers
- Platform constraints
- User flow difficulties
- Competitive pressures

### Design Opportunities

Areas where exceptional UX can differentiate the product:
- Innovation possibilities
- Delight moments
- Efficiency gains
- Competitive advantages

## Key Principles

- Treat discovery as collaborative conversation, not interrogation
- Ground decisions in documented evidence when available
- Focus on understanding real user needs, not assumptions
- Surface both constraints and opportunities
- Confirm understanding before moving forward
